# Реестр армии агентов

Правила армии (из AGENTS.md «Полный доступ и 24/7»; приказ мастера 16.11.2026 —
«всегда всё делай через армию» — действует в любом режиме, включая чат с мастером;
уточнение мастера 16.11.2026 — ВСЕ модели opencode/* сидят на одном аккаунте и жрут
лимит слона, поэтому армия живёт ТОЛЬКО на локальной Ollama, безлимит и офлайн):
- Слон-диспетчер создаёт worker-* по потребности под задачу и сразу записывает в этот реестр
- Основная рабочая сила — Ollama (порт 11434): безлимит, не зависит ни от кого; медленно
  (CPU, ~3 ток/с), поэтому задачи дробить на мелкие куски и гнать конвейером
- Параллельно 1–2 рабочих максимум (RAM 16 ГБ; вторая модель выгружает первую из памяти)
- Лимит слона (opencode-аккаунт) армия не трогает НИКОГДА: ни рабочие, ни рыбки
- Деплой, секреты и деньги — только слон; ни один рабочий их не трогает
- Рыбки проверяют всё: планы, код, отчёты рабочих
- Свободен/занят помечается строкой «СТАТУС: свободен / занят (задача) / убран (дата)»
