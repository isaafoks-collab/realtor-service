# Реестр армии агентов

Правила армии (из AGENTS.md «Полный доступ и 24/7»):
- Слон-диспетчер создаёт worker-* по потребности под задачу и сразу записывает в этот реестр
- Параллельно работает максимум 1–2 рабочих — бакет OpenCode общий, скорость даёт конвейер задач
- Деплой, секреты и деньги — только слон; ни один рабочий их не трогает
- Рыбки проверяют всё: планы, код, отчёты рабочих
- Свободен/занят помечается строкой «СТАТУС: свободен / занят (задача) / убран (дата)»
