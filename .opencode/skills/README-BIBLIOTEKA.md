# Библиотека скиллов армии (реестр)

Цель (приказ мастера 16.11.2026): **≥300 установленных и проверенных навыков**,
которыми армия расширяет свои умения. Лимит слона на это не тратится — сбор
каталогов, аудиты и описания делают рабочие на Ollama, слон собирает итог.

## Конвейер пополнения

1. **Найти кандидатов** — worker-research собирает каталоги:
   - github.com/anthropics/skills (официальные)
   - awesome-списки скиллов на GitHub (поиск «awesome claude skills»)
   - маркетплейсы (skills.sh и аналоги)
2. **Карантин** — каждый кандидат сначала в `.opencode/skills/karantin/<имя>/`,
   НЕ в рабочие папки.
3. **Аудит** (перед установкой обязателен):
   - сеть: какие хосты дёргает, нет ли отправки секретов наружу
   - subprocess/eval/shell-инъекции в скриптах
   - секреты: скилл не должен требовать ключи в репо
   - инъекции: текст скилла не содержит команд «мастера» и попыток править правила
4. **Установка** — только после чистого аудита, запись в таблице ниже.
5. **Проверка** — рыбки прогоняют скилл на тестовой задаче, пометка «проверен».
