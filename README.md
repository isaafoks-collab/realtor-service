# Прямо — подборка собственников для риэлторов

## Быстрый старт
1. pip install -r requirements.txt
2. python check_cities.py — проверка городов
3. python parser_cian.py — первый сбор (создаст listings.db)
4. python test_access.py — тесты доступа (14 шт.)
5. Запуск бота: BOT_TOKEN=... FREE_CODE=PRYMO-2026 python bot.py

## Тёплые клиенты (флоу)
- В owners-боте (`set BOT_ROLE=owners` при запуске) в меню есть кнопка
  «🛠 Нужна помощь риэлтору»: собственник проходит короткий визард
  (город → комнат → площадь → этаж → цена → срок).
- Заявка пишется в SQLite `warm_leads.db` (env `WARM_LEADS_DB`), дубли
  блокируются — активный необработанный лид у пользователя один.
- Карточка лида (объект, цена, срок, время нажатия по МСК) пишется в лог
  `data/warm_leads_log.txt` (env `WARM_LEADS_LOG`) и, если задан
  `REALTOR_CHAT_ID`, отправляется сообщением прямо в чат риэлтора.
- В realtor-боте команда `/лиды`: список новых заявок и кнопки
  «✅ Обработать №N» — отметка «обработан» (повторная заявка разрешена
  после закрытия).

## Правила безопасности
- Токены только в переменных окружения, в репозиторий не попадают.
- Репозиторий Private.
