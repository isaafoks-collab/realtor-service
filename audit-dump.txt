## Автономное утверждение плана

В автономном режиме слово «да» человека заменяется самоутверждением, но только так:

- Схема «слон и рыбки» работает как всегда: план, круги, блокирующие замечания
- Утверждай план сам только если: кругов не меньше 2, «блокирующих» ноль, в «Вопросы к человеку» пусто
- Каждый раз, когда утвердил сам, пиши в отчёт строку «САМОУТВЕРЖДЕНИЕ: <имя плана>» — человек проверит эти строки первым делом
- Есть блокирующие после 3 кругов или непустые «Вопросы к человеку» — СОСТОЯНИЕ: НУЖЕН ЧЕЛОВЕК, опиши вопрос, выбери безопасный вариант по умолчанию (тот, что не меняет данные) и продолжай по нему
- Выбор «ещё один круг или утвердить план с оговорками» — решение оркестратора (Алисы), не твоё: пиши вопрос в ОБСУДИТЬ С ЧЕЛОВЕКОМ и жди команду. Исключение: если правка плана мала (два-три пункта) и названа тобой конкретно — делай правку и ещё один круг сам, пометив «ЭКСТРЕННЫЙ КРУГ: <причина>»

## Деньги

Тратить деньги в автономном режиме запрещено по умолчанию. Исключение — только по явному разрешению человека, полученному через мост:

1) напиши в `most/status.md` в раздел ОБСУДИТЬ С ЧЕЛОВЕКОМ заявку: что нужно купить/подключить, зачем, сколько стоит, на какой срок
2) помощник человека (Алиса в чате Яндекса) прочитает заявку и спросит его; человек ответит «да» — Алиса подготовит текст команды
3) человек создаст GitHub Issue с меткой komanda, страж положит её в очередь `most/ochered-komand.txt`
4) только после появления команды в очереди выполняй одобренный шаг

Разрешение разовое и только на конкретный шаг из заявки. Самоутверждение деньги не разрешает никогда. Если для шага нужен платёж картой — его делает только человек; твоя часть — подготовить точную инструкцию, что именно он оплачивает и что делать после оплаты.

## Жёсткие стопы

Эти действия в автономном режиме запрещены, их не делает никто, включая самоутверждение:

- удалять файлы, папки, таблицы базы данных, ветки
- менять секреты, ключи, пароли, настройки VPS
- тратить деньги: подключать платные тарифы, покупать, подписывать — кроме шагов, одобренных по разделу «Деньги», и то без платежей картой: платежи картой делает только человек
- деплоить на прод, если деплой меняет данные пользователей, а не только код

Встретил такой шаг — СОСТОЯНИЕ: НУЖЕН ЧЕЛОВЕК, опиши, что он потребовал бы, и продолжай со следующего шага плана, его не трогающего

# strazh.ps1 — страж моста «слон и рыбки» (realtor-service)
# Живёт в фоне, раз в минуту: собирает команды из GitHub, ловит лимит, перезапускает агента
$ErrorActionPreference = "Continue"

$proj    = "C:\Users\Андрей\Documents\realtor-service"
$most    = Join-Path $proj "most"
$status  = Join-Path $most "status.md"
$serdce  = Join-Path $most "serdce.txt"
$ochered = Join-Path $most "ochered-komand.txt"
$log     = Join-Path $most "strazh-log.txt"
$repo    = "isaafoks-collab/realtor-most"      # публичный репо-почта (https://github.com/isaafoks-collab/realtor-most)

function Log($m) { "$(Get-Date -Format 'yyyy-MM-dd HH:mm:ss') $m" | Add-Content $log }

# один экземпляр стража
$mutex = New-Object System.Threading.Mutex($false, "Global\strazh-realtor")
if (-not $mutex.WaitOne(0)) { exit }

function SerdceStale([int]$min) {
    if (-not (Test-Path $serdce)) { return $true }
    return ((Get-Date) - (Get-Item $serdce).LastWriteTime).TotalMinutes -gt $min
}
function OpenCodeZhiv {
    return ($null -ne (Get-Process opencode* -ErrorAction SilentlyContinue))
}
function Zapustit($prompt) {
    Log "запуск OpenCode: $prompt"
    $cmd = "cd /d '$proj' && opencode run -c --auto `"$prompt`""
    Start-Process cmd.exe -ArgumentList "/c", $cmd -WindowStyle Hidden
}

while ($true) {
    try {
        # 1. Команды из GitHub Issues
        $raw = gh issue list -R $repo --label komanda --state open --json number,title 2>$null
        if ($raw) {
            foreach ($i in ($raw | ConvertFrom-Json)) {
                gh issue close $i.number -R $repo | Out-Null
                Add-Content $ochered ("[" + (Get-Date -Format 'MM-dd HH:mm') + " issue" + $i.number + "] " + $i.title)
                Log "команда из issue $($i.number) в очереди"
            }
        }

        # 2. Лимит: агент записал время сброса — страж ждёт и запускает
        if (Test-Path $status) {
            $st = Get-Content $status -Raw
            if ($st -match "СОСТОЯНИЕ:\s*ЖДУ ЛИМИТ" -and $st -match "СБРОС:\s*(\d{1,2}):(\d{2})") {
                $reset = Get-Date -Hour ([int]$Matches[1]) -Minute ([int]$Matches[2]) -Second 0
                if ($reset -lt (Get-Date)) { $reset = $reset.AddDays(1) }
                $reset = $reset.AddMinutes(5)
                Log "лимит; жду до $($reset.ToString('HH:mm'))"
                while ((Get-Date) -lt $reset) { Start-Sleep 60 }
                Zapustit "Ты слон. Ты молчал из-за лимита, он сбросился. Продолжай работу по правилам моста из most/README.md: прочитай most/status.md и очередь most/ochered-komand.txt."
                Set-Content $status ("СОСТОЯНИЕ: РАБОТАЮ`r`nОБНОВЛЕНО: " + (Get-Date -Format 'yyyy-MM-dd HH:mm:ss') + "`r`nЗАДАЧА: продолжение после перезапуска стражем")
            }
        }

        # 3. Завис: сердце молчит дольше 40 минут
        if (SerdceStale 40) {
            Log "сердце молчит 40 минут; перезапуск"
            Get-Process opencode* -ErrorAction SilentlyContinue | Stop-Process -Force
            Zapustit "Ты слон. Ты молчал сорок минут. Прочитай most/status.md, восстанови картину и продолжай последнюю задачу по правилам моста из most/README.md."
            Set-Content $serdce "restart"

## Автономное утверждение плана

В автономном режиме слово «да» человека заменяется самоутверждением, но только так:

## Деньги

Тратить деньги в автономном режиме запрещено по умолчанию. Исключение — только по явному разрешению человека, полученному через мост:

1) напиши в `most/status.md` в раздел ОБСУДИТЬ С ЧЕЛОВЕКОМ заявку: что нужно купить/подключить, зачем, сколько стоит, на какой срок

3) человек создаст GitHub Issue с меткой komanda, страж положит её в очередь `most/ochered-komand.txt`

# push-most.ps1 — публикация файлов моста в публичный репо-почту (realtor-most)
# Файлы моста лежат в корне репо-почты: status.md, ochered-komand.txt, serdce.txt (+ README.md)
$repo = "isaafoks-collab/realtor-most"
$most = Join-Path $PSScriptRoot ""   # папка most
$files = @("status.md", "ochered-komand.txt", "serdce.txt", "README.md")

foreach ($name in $files) {
    $local = Join-Path $most $name
    if (-not (Test-Path $local)) { Write-Host "нет файла: $name"; continue }
    $bytes = [System.IO.File]::ReadAllBytes($local)
    $b64 = [Convert]::ToBase64String($bytes)
    # sha текущей версии на удалённой стороне (для update); если файла нет — create
    $sha = $null
    $cur = gh api "repos/$repo/contents/$name" 2>$null | ConvertFrom-Json
    if ($cur -and $cur.sha) { $sha = $cur.sha }
    $payload = @{ message = "most: update $name"; content = $b64 }
    if ($sha) { $payload["sha"] = $sha }
    $json = $payload | ConvertTo-Json -Compress
    $tmp = Join-Path $env:TEMP "put-$name.json"
    # tmp-файл перезаписываем байтами, чтобы не затереть кириллицу cp1251
    [System.IO.File]::WriteAllBytes($tmp, [Text.Encoding]::UTF8.GetBytes($json))
    $resp = gh api "repos/$repo/contents/$name" -X PUT --input $tmp -H "Content-Type: application/json" 2>&1
    if ($LASTEXITCODE -eq 0) { Write-Host "pushed: $name" } else { Write-Host "FAIL: $name -> $resp" }
    Remove-Item $tmp -ErrorAction SilentlyContinue
}
