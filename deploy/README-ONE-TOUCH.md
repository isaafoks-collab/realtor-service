# ONE-TOUCH деплой realtor-service на VPS (5 шагов)

Сервер: UltraVDS u527081, 178.22.24.39, Ubuntu, root. Всё работает по расписанию
(systemd timer 07:00 МСК ежедневно) — ноутбук держать включённым не нужно.

## Шаги человека

1. Скопируй на сервер два файла любым удобным способом (scp/панель/ссылка):
   - deploy/install.sh (этот пакет)
   - deploy/env.template — заполненный

   Проще всего (после установки SSH-ключа слоном):
   scp deploy/install.sh root@178.22.24.39:/root/
   scp deploy/env.template root@178.22.24.39:/tmp/realtor.env

2. На сервере заполни секреты (один раз):
   nano /tmp/realtor.env
   - BOT_TOKEN — токен realtor-бота (из токены.txt локально)
   - BOT_TOKEN_OWNERS — токен owners-бота (на VPS не используется, но пусть будет)
   - REALTOR_CHAT_ID — чат риэлтора
   - GITHUB_REPO_TOKEN — токен с доступом на чтение private-репо (для клона и пуша базы)

3. Запусти ONE-TOUCH скрипт:
   bash /root/install.sh
   Он сам поставит пакеты, склонирует репо (по токену), сделает venv,
   перенесёт секреты в /etc/realtor/env (600, /tmp-копия затирается),
   включит таймер и СРАЗУ запустит первый прогон.

4. Проверь глазами первый прогон:
   journalctl -u realtor-morning -n 60 --no-pager
   - «Разбор данных завершён» — парсинг ок;
   - «[СВОДКА] отправлено: N лотов» — сводка ушла риэлтору в Telegram.

5. Ответь слону в чат «deploys» (или в очередь most/ochered-komand.txt).
   Дальше слон сам: возьмёт деплой под контроль, поставит SSH-ключ,
   включит ежедневные контрольные проверки и скажет «ПРОЕКТ ГОТОВ» после
   трёх зелёных утренних прогонов подряд.

## Что если что-то упало

- Человек получит Telegram-сообщение «[СБОЙ] утренний прогон на VPS» (автоматически).
- Диагностика: journalctl -u realtor-morning -n 100 --no-pager
- Повторный прогон руками: systemctl start realtor-morning.service

## Память (1 ГБ)

- unit ограничен MemoryHigh=700M / MemoryMax=850M — OOM-киллер не тронет чужое.
- Если ловим OOM — слон уменьшит объём городов в прогоне (решение фиксируется в журнале).
