## 2. Ограничения со стороны РФ (РКН / ТСПУ)

- **Cloudflare**: ECH заблокирован 06.11.2024 (сайты за Cloudflare падают); с 09.06.2025 трафик из РФ режется на 30–50%, обрывы после 16 КБ — Cloudflare-туннели для критичных сервисов не использовать
- **YouTube**: замедлен с 2024, к 2026 фактически недоступен без VPN — не считать источником для мастера
- **VPN**: ~200 сервисов заблокировано ТСПУ; с 01.09.2025 реклама VPN под КоАП (ст. 14.3) — VPN публично не рекламировать и не публиковать инструкции; личное использование легально
- Обходы живы: GoodbyeDPI, Zapret, Amnezia (восстановлена к июню 2026) — у нас установлен AmneziaVPN

## 3. Оплата зарубежных сервисов из РФ

RU-карты (Visa/MC РФ) не работают за рубежом с 2022. Рабочие классы решений:
зарубежная карта (Казахстан/Армения/Грузия/Турция), посредники (комиссия 15–30%,
риск для аккаунта), виртуальные карты зарубежных кошельков (комиссия 5–15%),
API-агрегаторы за рубли (aitunnel). Для бесплатных тиров проблема только в регистрации,
не в оплате.

## 4. Правила работы в РФ (чек-лист — применяется к каждому плану)

1. LLM-трафик — через локальные шлюзы (OmniRoute/freellmapi) или зарубежный VPS; OpenRouter из РФ не использовать
2. Регистрации в Groq/Gemini/Anthropic — только через VPN (Amnezia) или зарубежный IP
3. Аккаунты вне поддерживаемого региона не хранят невосполнимое; всегда запасной план
4. Mistral — приоритетный «западный» ключ; проверять статус при регистрации
5. Docker Hub работает, но зеркала образов держать; Cloudflare-туннели не использовать для критичного
6. websearch из РФ капчей/403 — исследовательский стек: Bing + Wikipedia REST + habr/vc.ru/zerocoder напрямую
7. Telegram на нашем VPS заблокирован хостером (UltraVDS, тикет в силе) — уведомления строить с запасным каналом (почта/SMTP)
8. VPN публично не рекламировать; личное использование — легально
