# Самозанятость (НПД): приём денег для проектов (исследование, ноябрь 2026)

Статус мастера: самозанятый. Документ — операционная база для монетизации
(игры, витрина недвижимости, подписки). Юридической консультацией не является.

## 1. База НПД (npd.nalog.ru, обновлено под 2026)

- Ставки: 4% от физлиц, 6% от юрлиц/ИП. Вычет 10 000 ₽ работает автоматически
  (4%→3%, 6%→4%), пока не израсходован
- Лимит: 2,4 млн ₽ за год нарастающим итогом; превышение = выпадение из режима до конца года. При приближении к лимиту — готовить ИП (УСН 6%)
- Чек — по каждому поступлению в «Мой налог» (lknpd.nalog.ru), можно отражать до 9-го числа следующего месяца
- Налог: квитанция до 12-го числа следующего месяца, оплата до 28-го
- Нельзя: перепродажа товаров, наём по трудовому договору, агентские договоры в интересах другого лица, подакциз/маркировка
- Можно: продажа продуктов собственного производства (ПО, игры — прямо в примерах ФНС)

## 2. Деньги из-за рубежа (для RF-резидента — почти всё закрыто)

- PayPal, Wise, Payoneer — не работают для РФ с 2022; GitHub Sponsors (через Stripe) и itch.io (через PayPal) — недоступны
- Передача реквизитов в банках под санкциями запрещена указом 2022 без разрешения ЦБ — «получить на Wise и перевести» легально не работает
- Посредники-агенты (принимают от зарубежной площадки, платят в РФ): применяются на практике, но у НПД запрет агентской деятельности в интересах чужого юрлица — серая зона, комиссия 10–20%
- **Вывод: монетизацию строить на российских площадках; зарубежные — только как витрины**

## 3. Веб-игры: кто реально платит самозанятому

- **Яндекс Игры — работает полностью «из коробки»**: сам формирует чеки и передаёт в ФНС; разработчику нужно только разрешить Яндексу в «Мой налог» → Партнёры. Ставка 6%. ЕЛС: РСЯ + сторонняя реклама + инап в одном договоре. Выплаты не чаще раза в месяц, минимум 3 000 ₽, порог достигнут — выплата в течение 20 рабочих дней следующего месяца
- CrazyGames/Poki: выплаты через PayPal/Payoneer/нерезидентский банк — для РФ-резидента прямые выплаты практически недоступны (актуальные 2026 условия проверить в их Docs из JS-браузера)
- Замены: VK Play (условия проверить), свой сайт + ЮKassa/ЮMoney (агрегаторы с авточеками для НПД — актуальный список на npd.nalog.ru/aggregators, проверить)
- Itch.io — только витрина без выплат

**Приоритет публикаций игр: Яндекс Игры → VK Play → свой сайт с российским агрегатором. CrazyGames/Poki — только если появится легальный канал выплат.**

## 4. Парсинг-сервис недвижимости — что учесть

- ToS площадок (ЦИАН и др.) запрещают автосбор — риск блокировок и гражданско-правовых претензий; работать по публичным данным, хранить минимум ПДн, обезличивать
- 152-ФЗ: если в данных есть ФИО/телефоны — мы оператор ПДн: политика ПДн на сайте, уведомление в РКН (обязательно с 01.09.2022), ПДн не передавать без согласия
- Продажа подписки/доступа — офертой на сайте + чек по каждому платежу

## 5. Чек-лист «первые деньги» (для мастера)

1. «Мой налог» — статус подтверждён (уже есть), ИНН единый во всех сервисах
2. Яндекс Игры: Консоль → Профиль → Документы → «Стать самозанятым» → подтвердить Яндекс в партнёрах → ЕЛС
3. Свой сайт: ЮKassa/ЮMoney с поддержкой НПД + оферта
4. Чек по каждому приходу (4% физлицо / 6% юрлицо, с вычетом меньше)
5. Налог до 28-го числа следующего месяца
6. Следить за лимитом 2,4 млн/год
7. Не принимать деньги мимо чека; зарубежные платформы — через официальный канал или не связываться

## Не проверено (нужен JS-браузер или мастер)

- Список операторов электронных площадок ФНС (npd.nalog.ru/aggregators)
- Детали Kwork/VK Play/ЮMoney по самозанятым (kwork.ru/faq отдал пустую страницу)
