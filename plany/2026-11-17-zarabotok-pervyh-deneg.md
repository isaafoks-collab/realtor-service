# План: первые заработанные деньги на ключ армии (контур А)

Дата: 2026-11-17. Запущен по приказу мастера (issue #2/#3 realtor-most, метка
komanda): «Раз просишь платный апи ключ на мистрал — заработай на него денег».

## Цель

Заработать первые 500–1500 ₽ на платный API-ключ для армии (aitunnel/Mistral,
~500–1000 ₽/мес) без чужих аккаунтов и без серых схем (РФ, НПД, белые деньги).
Способ: агент делает ПОЛНЫЙ продукт («под ключ»), мастер тратит ~15 минут на
аккаунт и публикацию. Продукт — исполнение заказных задач (боты, парсеры,
автоматизация), которые агент умеет делать сам даже на мёртвом каскаде
(детерминированные скрипты + сам слон на сборке).

## Деньги (проверяемая арифметика)

- Цель закупки: ключ ~500–1000 ₽/мес.
- Kwork удерживает комиссию продавца ~20% (точный % мастер видит в оферте при
  публикации — до постановки уточнить и записать в most/resheniya.md).
- Проверка вручную: заказ 1500 ₽ × 0.8 = 1200 ₽ нетто ≥ 1000 ₽ — хватает на
  ключ верхнего диапазона. Закупочные заказы дешевле: 3 кворка по 500 ₽ ×
  0.8 = 1200 ₽ нетто — тот же итог тремя мелкими продажами.
- НПД: чек на каждый приход через «Мой налог» (мастер, ~1 мин на чек).
- Протокол прозрачности: строки ОПЛАТА/ОПЛАЧЕНО в most/status.md по разделу
  «Деньги».

## Что делаю (этапы, всё исполнением агента, без LLM-армии)

1. **Мини-портфолио из 3 демо** (это и есть товар):
   а) Telegram-бот «сводка курса валют/новостей по расписанию» — код + инструкция
      запуска в 5 строк; работает на локальной машине заказчика, без сервера;
   б) парсер цен с любого сайта → xlsx (на базе скилла xlsx; детерминированный
      скрипт, пример — парсер объявлений, который у нас уже есть в проекте);
   в) пакет «автоотчёт»: скрипт, который собирает данные в папку и складывает
      готовый xlsx/сообщение в Telegram.
   Каждое демо: рабочий код, README на русском, скриншот результата.
   Секретов и ключей заказчика в коде нет — всё через env.
2. **3 карточки кворка** (текст для публикации мастером):
   - «Создам Telegram-бота под задачу — 500 ₽»;
   - «Напишу парсер сайта в Excel — 500 ₽»;
   - «Автоматизирую отчёт/рутину на Python — 500 ₽».
   К каждой: заголовок, описание, сроки (1–2 дня), что нужно от заказчика.
3. **Передача мастеру одним сообщением**: список из 3 карточек + 2 его шага
   (зарегистрироваться на Kwork по телефону, опубликовать карточки). Порядок
   и тексты — готовые, копипаст.
4. **Исполнение заказов**: получив текст задачи от мастера (мастер копирует
   ТЗ из кворка), агент делает работу сам, сдаёт в срок, мастер отправляет.
5. **Реинвест**: первые нетто ≥1200 ₽ → покупка ключа по протоколу «Деньги»
   (после строки ОПЛАТА в статусе и разрешения: приказ уже есть — «заработай
   и возьми», покупка ключа входит в приказ; траты сверх ключа — по протоколу).

## Правила расчёта и крайние значения

- Нули: заказов нет неделю — не отчаиваемся, снижаем цену до 300 ₽ и/или
  меняем заголовки; потолок простоя — 7 дней, потом доклад мастеру.
- Отрицательные суммы: не возможны (никаких предоплат из наших денег).
- Дубликаты: одинаковые заказы — один шаблон кода, цена за второй экземпляр
  −30% (проговорено в карточке).
- Пустые данные от заказчика: не берём заказ без ТЗ — уточняющий вопрос через
  мастера (общение с людьми — только мастер).
- Срыв срока: не берём в работу заказ, срок которого меньше 24 ч.

## Проверка, которую можно пересчитать вручную

После первого исполненного заказа мастер получает X ₽ нетто. Проверка:
(X = сумма заказа × (1 − комиссия Kwork)). Если X ≥ 1000 ₽ — ключ покупаем
сразу; если X < 1000 ₽ — продолжаем брать заказы до суммы ≥1000 ₽. Цифры
сверяются по фактической комиссии в интерфейсе Kwork (уточнить при
публикации, отклонение от 20% записать в most/resheniya.md).

## Что НЕ меняется (границы правки)

- VPS риэлтора и таймер — не трогаем (пусть работают сами).
- Никаких деплоев, никаких удалений, никаких смен секретов.
- Оригинальные файлы проекта (parser*, runner.py, db_*) не редактируем —
  только копии в prodazha/.
- Секреты в публичный репозиторий не попадают никогда.
- Публичная реклама VPN — запрещена; VPN в продукт не входит.
- Общение с заказчиками, регистрация аккаунтов, приём денег, чеки НПД —
  только мастер (риск бана, ручные сценарии «как человек»).
- Деньги: единственная трата — сам ключ (≤1000 ₽/мес), она входит в приказ;
  всё сверх — «НУЖЕН ЧЕЛОВЕК».
